# Phone Touchpad Plus 开源发布设计

日期：2026-09-29  
状态：已由用户确认

## 目标

将当前基于 Unrud/remote-touchpad 的中文增强版本，以
`ikedamiho41-hue3333333333/phone-touchpad-plus` 公开发布。项目面向希望把
iPhone 或其他智能手机用作 Ubuntu/Linux 多点触控板的用户，并提供可由
Codex 调用的安装、配置、诊断和维护 Skill。

发布工作不得改变本机正在运行的服务、配对密钥、访问地址、灵敏度、手势
配置或开机启动状态。

## 发布方式与许可证

- 使用 Unrud/remote-touchpad 的 GitHub Fork，公开仓库名称为
  `phone-touchpad-plus`，保留上游提交历史和 Fork 关系。
- 继续使用 GNU GPL-3.0，不删除 `COPYING`、原作者版权声明或源文件头。
- README 明确说明项目基于 Unrud/remote-touchpad，并区分上游能力与本项目
  修改。
- 修改版本带有显著的修改说明和日期；若将来提供二进制，同时提供对应源码、
  构建方法和许可证。
- Git 远程地址区分 `upstream` 与用户 Fork，避免向原作者仓库误推送。

## 产品定位与支持范围

名称：Phone Touchpad Plus  
中文名称：手机触控板增强版

首版重点验证：

- Ubuntu 24.04；
- GNOME X11；
- iPhone Safari；
- 手机和电脑处于同一可信局域网。

首版功能：

- 中文手机界面；
- 单指移动和点击；
- 双指滚动与捏合缩放；
- 三指或四指切换当前工作区中的应用；
- GNOME 活动概览和显示桌面；
- 独立的鼠标移动与滚动灵敏度；
- 二维码配对；
- 用户级 systemd 自动启动；
- 针对双指滚动误触发缩放和输入 `=` 的回归修复。

上游的 Windows、macOS 和 Wayland 代码保留，但文档必须明确标注这些平台的
中文增强功能尚未由本项目完成验证。

## 安装与生命周期

`scripts/install.sh`：

1. 检查操作系统、GNOME/X11、Go 和 X11 构建依赖；
2. 对需要系统级依赖的动作明确请求用户授权；
3. 从源码构建并安装到当前用户目录；
4. 为每台电脑生成独立的随机配对密钥；
5. 创建用户级 systemd 服务并设为登录后自动启动；
6. 输出手机访问地址和配对二维码；
7. 检测已有安装，不静默覆盖用户配置。

`scripts/doctor.sh` 只执行只读诊断，检查服务状态、端口、图形会话、网络地址、
所需文件和近期错误，并对密钥进行遮盖。

`scripts/uninstall.sh` 默认停止服务并删除程序文件，但保留用户配置。仅在用户
明确指定清除配置时，才删除配置和配对信息。

首版发布源码和本地构建安装脚本，不提供未经多环境验证的预编译二进制。

## Skill 设计

Skill 名称为 `phone-touchpad-plus`，采用正常自动发现方式。它在用户提出安装、
配对、调节灵敏度、查看状态、诊断连接、更新或卸载 Phone Touchpad Plus 时触发。

Skill 负责选择并调用仓库脚本、解释诊断结果以及验证服务状态。它不承担持续的
鼠标事件传输；实际控制仍由后台服务完成。

Skill 必须保留授权边界：只读诊断可直接执行；安装系统依赖、修改防火墙、重启
服务、更新或卸载前必须取得相应授权。失败时报告可验证证据，不循环执行高风险
操作。

## 隐私与安全

- 仓库不得包含真实配对密钥、局域网 IP、二维码、用户名、主机名或个人绝对
  路径。
- 文档和脚本使用 `$HOME`、运行时探测或参数，不写死开发机器目录。
- 生成的密钥和配置仅保存在目标用户目录，并使用用户级文件权限。
- README 明确提示：当前连接带配对密钥验证但不提供 TLS，必须仅在可信局域网
  使用。
- 示例二维码和地址只能使用虚构数据。
